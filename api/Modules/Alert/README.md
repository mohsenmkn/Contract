# ماژول هشدارها (Alert)

## هدف
نقطهٔ ورود ماژولار هشدارهای کاربر در نسخهٔ فعلی.

## پیاده‌سازی
- مسیر API: `GET /api/v1/alert` زیر `auth:sanctum`؛ پاسخ، کاربر احراز هویت‌شده را برمی‌گرداند.
- فایل مسیر: `routes/api.php`. منطق هشدارهای گردش قرارداد و اعلان‌های سامانه در بخش Contract و Notification نیز وجود دارد.
- فرانت‌اند اعلان‌ها و شمارنده‌های مرتبط را در layout/storeهای سراسری مصرف می‌کند؛ بررسی کنید با endpointهای قرارداد اشتباه گرفته نشود.

## وضعیت
این ماژول فعلاً endpoint دامنه‌ای کامل برای CRUD هشدار ندارد. پیش از توسعهٔ اعلان جدید، مالکیت اعلان، خوانده‌شدن، مجوز، و کانال ارسال را مشخص کنید.
