# ماژول طرف‌های قرارداد (Party)

## هدف
مدیریت اشخاص حقیقی/حقوقی طرف قرارداد و اتصال طرف مناسب به قرارداد.

## مسیرها و رابط کاربری
مسیرهای API در `routes/api.php` تعریف شده‌اند؛ فهرست endpointهای جاری را با `php artisan route:list --path=api/v1` بازبینی کنید. فرانت: `Front/src/views/Party/PartiesList.vue`, `PartyForm.vue`.

## مجوز و داده
مجوزهای پایه `parties.read/create/update/delete` هستند. اطلاعات هویتی و تماس طرف قرارداد حساس‌اند؛ دسترسی به آن‌ها را بر اساس مسئولیت قرارداد محدود کنید و برای ثبت پیمانکار، ارتباط کاربر پیمانکار با Party را بررسی کنید.
