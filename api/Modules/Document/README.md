# ماژول اسناد (Document)

## هدف
نقطهٔ ورود ماژولار اسناد و دسترسی‌های فایل در نسخهٔ فعلی.

## پیاده‌سازی
- مسیر موجود در `routes/api.php`: `GET /api/v1/document`، تحت `auth:sanctum`، بازمی‌گرداند اطلاعات کاربر واردشده.
- مجوزهای پایه در RBAC: `documents.read`, `documents.upload`, `documents.delete`.
- فایل قراردادها، سربرگ چاپ و تصاویر امضا هم‌اکنون در ماژول‌های Contract و Signature ذخیره/ارائه می‌شوند؛ endpoint عمومی این ماژول را با آن‌ها یکی ندانید.

## توسعهٔ بعدی
برای افزودن مخزن اسناد، نوع سند، مالک/قرارداد مرتبط، سطح محرمانگی، مسیر ذخیره‌سازی، کنترل دسترسی هر فایل، تاریخچهٔ بارگذاری و سیاست حذف باید تعریف شود.
