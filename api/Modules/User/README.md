# ماژول کاربران (User)

## هدف
مدیریت حساب‌های کاربری سامانه، جست‌وجو و فهرست کاربران قابل انتخاب، موقعیت‌ها، نقش‌ها و ارتباط سازمانی.

## مسیرها و فرانت
مسیرهای `/api/v1/users` شامل فهرست و CRUD کاربر، و مسیرهای کمکی `selectable` و `positions` است. فرانت: `Front/src/views/User/UsersView.vue`, `RoleList.vue`, `Profile.vue`, `Settings.vue`.

## نمایش اطلاعات
رابط کاربری نام نمایشی فارسی نقش را از backend می‌گیرد، اما شناسهٔ لاتین را برای ذخیره/اعمال دسترسی حفظ می‌کند. نام واحد سازمانی از نگاشت واقعی گرفته می‌شود؛ اگر نگاشتی نباشد، UI «بدون واحد سازمانی» نشان می‌دهد.

## امنیت و بهره‌برداری
ایجاد مدیر سامانه، فعال‌سازی حساب، تخصیص نقش و نگاشت واحد از اقدامات مدیریتی‌اند. نقش تنها دسترسی را تعیین نمی‌کند؛ وضعیت فعال حساب، policyهای backend و تعلق داده نیز بررسی می‌شوند.
