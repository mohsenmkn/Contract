# ماژول داشبورد (Dashboard)

## هدف
تجمیع آمار، نمودارها، موارد سررسیدشونده و داشبوردهای تفکیک‌شده بر اساس نقش.

## مسیرها و فرانت
مسیرها زیر `/api/v1/dashboard` تعریف شده‌اند؛ شامل داشبورد واحد و پیمانکار، آمار قرارداد و صورت‌وضعیت، نمودار مبلغ/وضعیت، موارد نزدیک به انقضا و فعالیت‌های اخیر. فرانت در `Front/src/views/Dashboard/` شامل `ContractDashboard.vue`, `UnitDashboard.vue`, `ContractorDashboard.vue` و `ExecutiveDashboard.vue` است.

## دسترسی
مجوز پایه `dashboard.view` است؛ ولی پاسخ باید به نقش، واحد سازمانی و پیمانکار جاری محدود باشد. از نمایش دادهٔ کلی سازمان به کاربر واحد یا پیمانکار جلوگیری کنید.
