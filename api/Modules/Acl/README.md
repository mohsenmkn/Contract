# ماژول دسترسی‌ها (Acl)

## هدف
مدیریت نقش‌ها، مجوزها و گروه‌های کاربری مبتنی بر RBAC. شناسه‌های فنی نقش لاتین می‌مانند و عنوان/شرح فارسی برای نمایش و مدیریت ثبت می‌شود.

## پیاده‌سازی
- تعریف مجوزها، برچسب‌ها و نقش‌های پیش‌فرض: `api/config/rbac.php`.
- مسیرها: `routes/api.php` با prefix `/api/v1/acl` و گروه `/api/v1/acl/groups`.
- APIهای نقش و مجوز شامل فهرست، ایجاد، ویرایش و حذف؛ API گروه‌ها شامل مدیریت گروه و تخصیص کاربران است.
- فرانت: `Front/src/views/Acl/GroupsView.vue` و صفحهٔ نقش‌ها در گروه User؛ `RoleModal.vue` برای مدیریت عنوان فارسی نقش.

## نکتهٔ بهره‌برداری
پس از تغییر نقش یا مجوز، دسترسی کاربر را با نشست واقعی بررسی کنید. نقش‌های پایگاه داده و `default_roles` کد ممکن است نیازمند همگام‌سازی باشند. `super_admin` نقش دارای دسترسی کامل است؛ آن را فقط به مدیران سامانه بدهید.
