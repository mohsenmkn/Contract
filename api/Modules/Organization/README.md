# ماژول سازمان (Organization)

## هدف
مدیریت واحدهای سازمانی و نگاشت کاربران به واحد، نمایندهٔ واحد و افراد مجاز به امضای قرارداد واحد.

## مسیرها و فرانت
- CRUD واحدها: `/api/v1/organizational-units`.
- نماینده: `/organizational-units/{id}/representative`.
- امضاکنندگان قرارداد: `/organizational-units/{id}/contract-signers` (دریافت، تخصیص و همگام‌سازی).
- فرانت: `Front/src/views/Organization/UnitsList.vue`, `UnitForm.vue`.

## مدل مسئولیت‌ها
یک واحد می‌تواند بیش از یک کاربر مرتبط داشته باشد. تنظیم‌کنندهٔ قرارداد و امضاکنندگان (رئیس، مدیر و معاون) مسئولیت‌های جداگانه‌اند؛ هر فرد باید با نقش صحیح و همان واحد نگاشت شود. مدل‌های `OrganizationalUnit` و جدول نگاشت را پیش از تغییر schema بررسی کنید.

## مجوز
مجوزهای پایه با کلید `units.*` تعریف شده‌اند؛ endpointهای امضاکنندگان و تغییر نگاشت باید فقط در اختیار مدیران مجاز سازمان باشد.
